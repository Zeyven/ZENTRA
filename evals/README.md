# Evaluation gates

E0 Chat, E1 Research, E2 Work, E3 Build, E4 Long-running, E5 Tool/Permission, E6 Memory/Context, E7 Safety/Red-Team are reserved according to white paper §15.

M0 has no agent behavior and runs deterministic engineering tests only. Agent suites are NOT IMPLEMENTED / NOT VERIFIED, not passing empty suites. EvalRunner starts at M4. Any confirmed security hard-gate failure blocks release regardless of quality averages.
