# 营业界面首轮修复

## 已实现
- 钟房将休息技师从等待队列移出，明确显示等待、在钟、休息、下班和未知状态。
- 将 PostgreSQL numeric 字符串转换为数字后汇总，避免完成钟数拼接。
- 技师在钟标签以状态字段为准，不再依赖房间详情是否可见。
- 房间服务映射排除退单和商品；叫钟前复核当前已加载的技师状态，加载失败时禁止叫钟。
- 明确展示“今日已完成钟数”，说明该指标与自动派钟的已接钟数不是相同口径；播报不等于派工。
- 钟房配置入口使用 settingsManage / technicianManage 细分权限，服务器授权规则不变。
- 排钟顺序保存检查返回失败，不提前关闭弹窗。
- 设备配置保存前复核账号权限；版本冲突重新读取配置，要求重新打开核对，刷新失败不误报为保存结果未知。

## 验证与边界
- 两项新增数值/状态回归测试及已有操作反馈测试通过（3 项）。新增测试纳入 test:core。
- 客户端 TypeScript 检查和 Web 生产构建通过。
- 本轮未改变数据库、派钟算法及权限上限。
- 未进行完整浏览器交互验收、全量业务回归或实体设备测试。
- 未发布云端或安装包；这是首轮局部修复，不代表竞品调研提出的全部优化已完成。
