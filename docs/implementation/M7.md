# M7 — Chat / Conversation

状态：进行中，未通过 Definition of Done。

Conversation 现在可保存用户消息。`POST /v1/conversations/:id/messages` 要求有效会话、Workspace OWNER、活跃 Conversation 和 Idempotency-Key；同一 key 与正文重试返回原消息，变更正文返回冲突。消息在 Conversation 内按递增序号追加，不允许客户端指定作者身份。`GET /v1/conversations/:id/messages` 提供活跃成员可读的 keyset 分页。归档的 Conversation 不接收新消息，恢复后原消息仍在；若它关联的 Project 已归档或删除，也禁止追加新消息。

消息正文只保存于受 Workspace RLS 保护的 `conversation_messages` 表；应用数据库角色没有直接写权限，写入通过数据库函数重新验证 OWNER 身份并锁定 Conversation。插入触发的 Audit 和 Outbox 与消息同事务提交，事件仅含标识、序号和作者类型，不复制正文。集成测试覆盖权限、重放、分页、归档、恢复和事件边界。

目前只支持用户消息。ASSISTANT 消息没有公开写入路径，也没有模型调用、Agent Run 或流式回答。Desktop Chat 可以保存、查看、导出和删除本机笔记；这些笔记尚未接入此 API，也不会发送给模型。真实 Clerk 登录、正式消息同步、Agent 回复、附件、资源引用和发布验收未完成；`/health/ready` 继续返回 503。
