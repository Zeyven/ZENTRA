# M2 实施记录：Core Domain

状态：**PARTIAL**。M0/M1 工程 DoD 已通过；M2 的数据库骨架、Project、Task 草稿、Conversation 与 Resource 元数据垂直切片已运行，但其余实体 repository 与生命周期尚未完成，不进入 M3。

## 已实现

- PostgreSQL 表：Project、Task、Run、Conversation、Resource、Artifact、Approval、AuditEvent、OutboxEvent。每个租户实体显式保存 `workspace_id`，跨表组合外键验证同 Workspace 和同 Task/Run 关系。
- Task 与 Run 分表；Artifact 的 `task_id` 非空且存在数据库外键，Run 可选但必须属于同一 Task；Approval 绑定 user、task、run、action、resource、arguments hash、state version 与 expiry。
- 全部 M2 租户表启用并强制 RLS。Project 的写入限定 Workspace OWNER，MEMBER 可读；Project 版本触发器禁止跳号，租户和实体 ID 不可变。
- Project 创建和更新通过数据库触发器在同一事务写 Audit 与 Outbox。API 提供 `POST /v1/projects`、`GET /v1/projects`、`GET /v1/projects/{id}` 和 `PATCH /v1/projects/{id}`，使用已验证 AYRA 会话、Policy、RLS 和乐观并发版本。
- Project 创建要求 `Idempotency-Key`，同 Workspace、操作范围和键只保留一个结果；请求内容变更返回 409。幂等记录与 Project/Audit/Outbox 在同一事务提交。
- Task 草稿提供创建、列表、详情、版本化更新和软删除 API。创建要求 `Idempotency-Key`；创建后 `currentRunId` 为 `null`，不会隐式启动 Run。OWNER 可写，MEMBER 可读，Project 关联必须属于同一 Workspace。Task 创建、更新、软删除在同一事务写 Audit 与 Outbox。
- Project 提供版本化归档与恢复；普通列表和详情隐藏归档项，`archived=true` 可列出归档项。归档 Project 后不允许为其创建 Task；两种状态变更各产生审计和 Outbox 事件。
- Conversation 元数据提供幂等创建、列表、详情、版本化改名、归档与恢复。此阶段不伪称已实现消息存储或对话 Agent；四类写入事件与实体同事务提交。
- Resource 输入材料元数据提供幂等创建、列表、详情、版本化改名和软删除；sourceRef 在创建后不可通过普通更新改变。此阶段尚无文件上传、签名访问或内容解析。Resource 与输出 Artifact 保持独立。
- 关联 Project 的创建请求先确认幂等重放，再在新建路径锁定并验证 Project 仍活跃；已成功请求在 Project 后来归档时仍返回原实体，新请求被拒绝且不会留下未完成的幂等记录。

## 本地验证

- `pnpm migrate` 已应用 `0004` 至 `0010`；迁移校验和与重复执行规则继续生效。
- `pnpm test:core` 在真正的 PostgreSQL 18 上验证跨 Workspace 引用拒绝、Task/Run/Artifact 约束、Approval 对应 Run、Project 版本冲突、OWNER/MEMBER 权限，以及回滚时 Project/Audit/Outbox 一起消失。
- `pnpm test:api` 以签名 JWT 经身份适配器进入真实数据库，验证 Project 创建、列表、详情、跨租户隐藏、MEMBER 只读、撤权和旧版本更新 409。
- 同一 API 测试验证重复创建键得到同一个 Project、改动内容被拒绝，且 Project 创建的 Audit/Outbox 事件各只有一条。
- Task API 测试验证草稿不等于 Run、幂等重试、版本冲突、OWNER/MEMBER 权限、跨租户隐藏、软删除与三个事件各只写一次；数据库测试验证 Task 事务回滚时实体、Audit 与 Outbox 同时消失。
- Project API 测试验证归档与恢复、旧版本冲突、归档项列表隔离、MEMBER 拒绝归档，以及审计和 Outbox 各写一次。
- Conversation API 测试验证幂等创建、OWNER/MEMBER 权限、跨租户隐藏、版本冲突、归档与恢复、事件单次写入，以及回滚时 Conversation/Audit/Outbox 一起消失。
- Resource API 测试验证幂等创建、OWNER/MEMBER 权限、跨租户隐藏、版本冲突、软删除、事件单次写入，以及回滚时 Resource/Audit/Outbox 一起消失。
- API 测试验证 Project 归档后旧 Task/Conversation/Resource 创建键继续重放，而新建 Resource 返回 404 且不遗留幂等预留记录。
- 完整 `pnpm check` 与远端 CI 在本次提交后复验；此处不以骨架表存在代替 M2 完成。

## 尚未完成

Task 执行态与 Run、Artifact、Approval 的 repository、写入 API、Domain 状态迁移和完整审计/Outbox 仍待实现。Conversation 消息层、Resource 文件处理、Artifact 软删除、retention purge 骨架及端到端生命周期测试仍待实现。M2 Definition of Done 尚未全部满足，M3–M12 不标记开始。
