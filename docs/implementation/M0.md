# M0 实施与验收记录

- Milestone：M0 Repository & Engineering Foundation。
- Baseline：AYRA BASELINE v1.0 — FROZEN；原白皮书未修改，SHA-256 见 `docs/baseline/SOURCE.sha256`。
- 总体状态：PARTIAL；本地工程检查已通过，基础设施与原生/远程 CI 验收未完成。M1–M12 未开始。

## 已实现

按 §3.3 建立五个应用与十三个共享包的 pnpm workspace。Web 使用 Next.js / React，桌面使用 Tauri 2 / React，移动端使用 Expo / React Native，API 使用 Fastify / OpenAPI，Worker 独立进程。当前客户端是明确标示的开发预览，不包含模拟账户、模拟任务或模拟授权。

建立共享严格 TypeScript 配置、ESLint、Prettier、Vitest、依赖锁文件和 GitHub Actions。Domain 的类型独立于供应商。静态工程检查限制 Domain 外部依赖，以及客户端引用敏感服务端包；它不替代后续的完整安全测试。

配置解析对缺失必要字段失败，数据库 URL 只接受 `application_role`，错误信息不回显凭据。环境初始化生成随机本地凭据、设置文件权限并保留已有环境文件。原有 `.env.local` 未读取到输出、未覆盖或加入 Git。

Compose 定义 PostgreSQL 18、Redis、Temporal dev 与 S3-compatible MinIO。API `/health/live` 只表示进程存活；`/health/ready` 返回 503。Worker 不接受任务。无任何用户仓库或模型驱动 shell 在宿主 API 中执行。

## Definition of Done

所有 app 的独立构建、CI lint/typecheck/unit、本地环境一条命令启动三项需全部有通过证据后才能标记 M0 PASS。当前未全部满足，按白皮书 §0.2 / §20 不进入 M1。

## 已知限制与 OPEN

当前没有账户、Workspace 授权、任务执行、供应商 Adapter、审批、Vault、Sandbox、Memory、Commerce 或正式发布能力。这些按 M1–M12 顺序实现。正式价格、模型路由阈值、生产云、SLO、Retention、品牌和合规仍保持 OPEN。

Docker 镜像实际拉取、角色初始化、Temporal namespace 和 S3 读写需要运行中的容器环境才能验证。仅检验 Compose 文件不能代替这项验收。移动端 JS/assets 导出也不代表 IPA/APK 已在真机验证。

## 变更范围与回滚

新增 `apps/`、`packages/`、`scripts/`、`infrastructure/`、`evals/`、`docs/` 及根工程配置；保留已有环境与计划资料。GitHub Actions 现有骨架由对应脚本补齐，并针对实际目标分支 `ZA-AYRA` 触发。目标仓库原有 MIT LICENSE 保持不变；完整白皮书文本不提交到公开仓库。

M0 没有业务数据库迁移。`pnpm infra:down` 保留数据卷；代码可按文件回退，禁止自动删除 `.env.local`、计划文件或数据卷。生产环境未被修改。
