# 硬件自动接入验收要求（FROZEN）

用户明确要求：自动检测、一键配置、真实可用，未彻底实现不得标记完成。此文件固定完成标准，不授权猜测协议、跳过验证、复用原厂凭证或影响正在营业的设备。

## 必须完成

1. Windows 客户端能检测目标设备及连接方式。普通键盘、网络邻居、已保存资料不能自动认定为目标硬件。
2. 一键应用有依据的连接参数；设备用途、房间和区域必须明确。保护已有配置及其他商家、门店。
3. 配置能被实际运行的连接程序使用，不能以保存草稿代替驱动接入。
4. 实体点钟王完成注册/登录、菜单、房态、支持的上下钟业务；重复、失败、断线及撤销授权行为经过验证。
5. 实体刷牌器正确读取卡号、保留前导零，使用正确门店绑定；普通手工输入或模拟键盘事件不算真实设备验收。
6. 实体技师房报钟器完成指定区域的叫号，验证送达或由现场人员核实播放；当前电脑语音不代替远端设备播报。
7. Windows 安装/升级后完成检测→配置→运行→实际操作，以及退出、切店、端口冲突、断网与恢复验收。

## 当前判定

整体：**未完成；实机及缺失厂商业务合同阻塞**。

仍缺：当前固件设备注册合同、完整菜单和业务映射、钟房机顶盒播报合同、真实目标硬件操作及安装后现场验收。

这些缺口不能通过更多保存表单、把状态改为 connected、把模拟器测试称为实机验证，或承诺持续搜索来消除。现有文件和代码状态不构成上述完成证据。
