# 技术后台门店生命周期管理

入口：平台管理 → 商家管理 → 对应商家的门店管理。

- 停用：禁止新营业，保留历史和员工授权，允许恢复。
- 恢复：仅未永久删除的门店可恢复。商家本身被停用时不绕过商家限制。
- 强制删除：永久移除营业门店，隐藏商家端与顾客入口，断开门店实时连接。平台记录保留“已永久删除 · 不可恢复”，没有恢复操作；门店编号不复用。
- 强制删除不是物理清空财务历史。连锁资金、跨店引用及审计保留，避免损坏其他门店权益和对账。

强制删除要求操作原因、精确门店编号和当前平台密码。并发修改检查门店版本，重复请求不能二次执行。密码不进入平台审计，审计记录操作人、商家、门店、原因与前状态。

027/028 增加永久删除标志和管理版本。运行账号 RLS 隐藏已删除门店；触发器拒绝任何更新或恢复已删除记录。平台仅可调用限定参数的管理函数，函数执行人没有 BYPASSRLS，绑定指定商家上下文并恢复原上下文；不向平台运行账号授予业务表直写权限。门店管理持有商家事务锁，等已进入的业务事务完成后更新，避免旧会话在删除后继续落单。
