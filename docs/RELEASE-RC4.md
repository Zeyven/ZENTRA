# 1.0.0-rc.4 管理体验修复（2026-09-08）

## 修改与根因

- 平台控制台原本只设置最小高度，配合全局 body overflow:hidden，矮窗口内容超出屏幕后无法滚动。增加独立视口滚动容器及侧栏滚动，覆盖桌面和窄屏六个工作区。
- 商家管理的门店增加停用、恢复和空门店删除确认。删除要求门店已停用，数据库外键阻止删除有配置、员工授权或经营关联的门店；请求诊断日志可随空门店清理，删除失败则事务整体回滚，审计保留。
- 会话刷新不再携带可能已删除的门店 ID。实时连接失去门店权限时重新验证账号和可用门店；有效账号不再因删除当前门店被误退出，失效账号仍拒绝访问。
- 登录、激活、创建员工和修改密码统一提供显示/隐藏按钮。
- 商家端按商家编号记忆账号，平台端独立记忆账号；可取消记忆，均不保存密码。保留老板首次激活后刚填写的账号，避免输入商家编号时被记忆逻辑清空。
