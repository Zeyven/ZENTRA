# V1.0.3 安装器关闭检测修复

2026-09-09。V1.0.2 曾在客户端已退出后反复提示“无法关闭”。原包重启安装后成功，但不是源码修复。

## 调查和实现

锁定 electron-builder 26.15.3 自带的 CHECK_APP_RUNNING。其 PowerShell 分支按路径 StartsWith(INSTDIR) 匹配所有进程，未精确匹配目录边界和可执行文件；用 app 与 app-other 两个目录的受控进程已复现前缀误判。原现场 PowerShell 命令和最小 NSIS 探针独立运行均可正确返回，缺少原安装器内部状态日志，不能断言该前缀误判就是原现场的唯一原因。

通过官方 customCheckAppRunning 扩展替换原检查流程，不修改 node_modules：

- 精确匹配安装目标的 ZA-Thera.exe；同名其他目录进程保持运行。
- 固定脚本以 UTF-16LE 编码传入 PowerShell，安装路径通过独立进程环境变量传递，不拼接为脚本；支持中文、空格和单引号路径。
- 使用 NoProfile / NonInteractive，不加载用户 PowerShell 配置，不改变执行策略或权限。
- 明确返回 0（已退出）、10（仍运行）、20（无法检测/关闭）；启动失败、超时及未知状态均阻止安装，不当作成功。
- 提示保存工作，经确认后先请求关闭窗口，再等待退出，必要时只终止目标可执行文件；重试重新读取状态。NSIS 输出和退出码均显式出栈，避免混淆检测状态。
