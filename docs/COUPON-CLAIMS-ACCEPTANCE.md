# 到店核验与顾客领券

真实活动具有门店归属、券类型、门槛、有效期、总量与乐观版本；默认停用，无示例权益。老板在设置维护活动，具备会员及优惠权限的店长可从会员管理的“到店领券”核验身份并生成 30 分钟专属链接。

链接只承载随机令牌，数据库仅保存哈希。顾客领取时重新检查商家、门店、核验人员当前权限、会员、活动版本和余量。行锁、唯一约束及事务保证不同重试键也只发一张券，总量不会并发超发。活动变更、核验人员撤权及邀请过期均拒绝新增权益。顾客只能读取本邀请的券信息，不能查询会员身份或资产。

短信认证接口明确返回未接入；到店核验需要员工主动确认并记录原因，不冒充手机验证码认证。公共领取响应直接返回已落库优惠券，刷新读取真实回执。读请求超时明确反馈，新读取和领取操作废弃旧读取结果，避免旧响应覆盖成功状态。

接口回归 3/3 通过。浏览器老板创建活动、核验会员、顾客双击领取及刷新只发一张券通过；店长会员页核验并生成链接通过，同时验证其页面不显示活动创建/编辑入口。全套上线验收仍单独执行。
