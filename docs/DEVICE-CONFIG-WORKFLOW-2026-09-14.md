# 门店设备配置流程修正

本次修改源代码，未发布云端或安装包，不改变既有设备授权。

- 点钟王：网关表单支持 1–100 台面板，逐台填写房间、IPv4、设备编号；阻止重复 IP 或编号。电脑监听地址与面板地址分别说明，配对文件包含选定的监听 IP 和端口，不再要求手改文件。
- 授权列表：返回并显示房间、面板编号、IP。查询仍在当前商家事务和门店范围内，不返回密钥。更改已签发绑定仍需撤销并重新签发。
- 刷牌器：独立输入检测保留前导零，可由回车或按钮读取；不创建订单或修改卡号绑定，不把键盘手输当成硬件已连接。提供现有手牌绑定与营业查询的位置说明。
- 报钟器：网络连接才显示网络端口；串口连接显示串口名称与 COM 示例。保持每店一份草稿的现有数据模型。
- 资料登记：与接入操作分开说明，并按 settingsManage 权限控制配置入口。

限制：网关仍为只读联调；生产 Windows 客户端不会因下载配置自动运行此测试网关。厂商报钟、注册、播报协议及实机验证尚未完成。本次没有实现多播报终端管理或专用 USB/串口刷牌驱动。

验证：TypeScript 检查、服务端/Electron/Web 构建、网关真实数据库隔离测试、4 项设备就绪状态测试通过。浏览器覆盖多面板、重复 IP 拦截、下载参数、绑定回显、撤销授权、读卡前导零，以及播报草稿保存/刷新/两个入口一致性。端口改为条件显示后，测试显式选择网络连接，并使用 combobox 的可访问名称定位下拉框。
