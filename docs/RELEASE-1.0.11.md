# V1.0.11 面板协议安全修正

2026-09-15，Web、API、Windows stable 与 rc 更新渠道发布 1.0.11。独立发布目录为 `/opt/za-spa-saas/releases/20260915T072657Z`，前一版本目录保留在 `/opt/za-spa-saas/releases/20260915T064253Z`。发布前备份为 `/opt/za-spa-saas/backups/pre-1.0.11.dump`，`pg_restore --list` 可读取；未执行完整恢复演练。

本版修正点钟王测试网关的协议边界：厂商日志证实了 `SystemClockInfo` 请求形状，但未提供当前固件的房态响应字段合同。因此网关不再将澜序内部房态转换为推测的 `status`、`t1` 至 `t5` 字段并发送到物理面板；该请求现在返回明确失败，不读云端房态。虚拟点钟王同样只测试拒绝路径，不再模拟成功房态。协议解码器同时仅接受厂商服务定义和现场帧所示的单向 `OnAskCall` 类型，拒绝未证实的普通请求/应答类型。

本地验证：22 项硬件网关测试、类型检查、contracts/server/Web/Electron 构建、包内 31 个文件及更新元数据校验通过。1.0.10 → 1.0.11 的隔离安装、升级、卸载流程退出码均为 0；安装后的 `app.asar` 与包内构建一致；原有 1.0.3 安装、注册项、快捷方式及用户数据均已恢复。该验证不包含已安装客户端自动下载、安装、重启的完整交互链路。

安装包 `ZA-Thera-1.0.11-Windows-x64.exe` 为 112,975,877 字节，SHA256 为 `545891874b592572048b85e1207217ee6ba69d92c0295de5227f894310cd06cb`。公网下载文件 SHA256 与本地一致；stable/latest.yml、rc/rc.yml 均为 1.0.11；固定下载别名返回 200 和正确大小。公网 `/ready` 返回 1.0.11，未认证网关管理接口返回 401，SaaS 服务 active，Nginx 配置检查通过。

生产数据库此前已完成 034 硬件绑定唯一索引迁移：同一网关内房间和 IP 均不可重复绑定。此次发布没有新增数据库迁移。

限制：安装包未签名；真实 7 寸面板的响应字段、菜单业务映射、设备注册授权、报钟写入及钟房播报均没有完成厂商协议和实机验收。不能将本次发布视为真实设备已接通。

回滚：保留前一发布目录、1.0.10 安装包、`stable/pre-1.0.11.yml` 和 `rc/pre-1.0.11.yml`。如需回滚，切回前一目录并重启 SaaS，同时恢复两个更新清单和下载别名；已安装 1.0.11 的客户端不会自动降级。
