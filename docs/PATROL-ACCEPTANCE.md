# 楼面巡房

原页面调用的新 SaaS 接口缺失，现已实现 `/patrol` 与 `/patrols`。身份、门店、房间及操作人都由服务端验证，只有老板或授权店长、收银可记录；支持会话只读。

按北京时间统计当日每间房最新巡查结果，历史列表最多显示最近 200 条，房间状态单独取每房最新记录，不受历史列表截断影响。异常必须填写说明，不改变房态或订单。锁定房间并比较预期巡查编号，拒绝其他终端已经更新的旧结果。

保存直接返回已提交记录、当前列表与汇总；界面防重复点击，结果不明时锁定操作并使用原请求重试。失败保留异常输入，成功后关闭。事件 `room.patrol` 驱动授权终端更新。

后端 2/2 通过：同键重试只记录一次、并发版本冲突、跨商家拒绝、输入校验及撤权。浏览器丢响应后原键重试通过，数据库仅一条记录。首次浏览器定位同时匹配房态卡和巡房按钮，改为使用已观察到的精确按钮名称后通过。
