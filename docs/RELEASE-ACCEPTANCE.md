## 同机容量实测

在 API 768 MiB / 60% 单核 CPU、PostgreSQL 1 GiB / 60% 单核 CPU 配额下，隔离测试环境创建 20 家商家、每家 5 店、100 条已认证实时连接。每店 3 间房，100 个客户端分散请求房态，每 30 秒提交一次巡房；测试持续约 125 秒。

- 2,800 次请求，0 失败；P95 964.45 ms，最大 1,417.73 ms。
- 401 条实时事件，无跨商家事件，结束时 100 条连接均有效。
- 旧服务 62 次健康检查全部通过，P95 17.46 ms。
- 新 API 峰值内存约 105 MiB；数据库约 296 MiB。资源配额未上调。

这是上述数据规模和请求组合下的初步容量验收，不代表任意历史数据量、重报表或所有门店同时密集结账时均能保持此延迟。生产经营数据尚为空。
