# 许可证

ZENTRA 采用 [Elastic License 2.0（ELv2）](../LICENSE)，属于 **源码可得（source available）** 软件。

本文用于通俗说明许可边界。最终法律效力以仓库中的 [LICENSE](../LICENSE) 正文为准。

## 这算开源吗？

不是 OSI 定义下的开源许可证。

ELv2 允许公开查看源码、修改、分发和自托管，但包含商业使用限制，因此更准确的表述是 **source available**。

## 可以做什么？

在遵守 ELv2 条款的前提下，你可以：

- 本地运行或自行部署
- 个人使用或公司内部使用
- 阅读、修改和二次开发源码
- 分发修改后的版本
- 基于本项目开发自己的应用或解决方案
- 将本项目集成到其他软件系统中
- 使用本项目进行商业项目开发

## 哪些行为受到限制？

ELv2 的核心限制包括：

- 不得将本软件本身作为托管或管理服务提供给第三方，并向第三方开放本软件的大部分核心功能
- 不得规避、关闭或修改软件中的许可证密钥保护机制（如存在）
- 不得删除、隐藏或篡改许可证、版权及其他权利声明

如果未来需要将 ZENTRA 或相关软件作为面向第三方的托管 SaaS / Managed Service 提供，应另行取得商业授权。
