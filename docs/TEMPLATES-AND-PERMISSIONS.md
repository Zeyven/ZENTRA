# 商家模板与门店功能授权

商家模板使用独立的 `merchant_templates`，每条记录必须归属商家。模板包含项目商品、会员等级、充值方案、优惠券配置；严格校验字段，不接受会员姓名、电话、卡号、余额、次数或积分资产。

下发必须选择本商家的明确门店，先调用预览接口，再提交预览哈希。服务端锁定模板与目标配置，重新核对版本和当前值；任何变化使整次操作回滚。目标配置通过包含商家和门店的外键绑定，不按名称覆盖门店自建记录。首次下发的商品库存为 0，后续下发保留库存；停用模板保留已有下发配置与审计记录。下发优惠券配置后，需在会员详情中向指定会员实际发券，单次提交与重试具有幂等保护。

门店页面授权同时约束服务端功能。共享收银依赖使用单独的、需关键词的会员查询接口，返回最多 20 条必要字段；房态快照不携带会员目录。管理功能被撤销后不能继续读取明细、报表、库存或充值。技师快照只返回本人服务与金额。现有实时连接按当前授权重新校验，撤销全部功能后断开；事件游标排除未授权模块，另一门店授权不受影响。

配置维护支持授权可更新门店配置，仍不可执行充值、结账等经营资产操作。支持访问记录平台操作人、授权和审计明细；授权撤销后下一次接口调用被拒绝。

证据：`tests/templates.test.ts`、`tests/page-permissions.test.ts`、`tests/browser/templates.spec.ts`。浏览器已验证新建、选店、预览、重复点击、预览冲突、下发记录和向指定会员发券。停用模板已通过 API 测试，尚未做对应浏览器点击验收。此记录不代表完整旧功能验收通过。
