# 澜序视觉规范

2026-09-08：按用户“高级、简约、有展示感”的要求实施。品牌与素材来源见 `BRANDING.md`。

## 视觉方向

- 深墨绿侧栏 `#193B30`、暖白画布 `#F4F6F2`、玉绿主按钮 `#315E50`。
- 香槟金 `#D2C6A3` 仅用于登录页标语等少量品牌重点，不用于虚构业务指标。
- 系统字体、本地 SVG、CSS 几何背景；不依赖外部字体或图片请求，不给高频操作添加等待动画。
- 中文业务标签优先；品牌区少量英文辅助。导航使用统一线性 SVG 图标。
- 房间状态同时显示文字、色签和顶部色线。告警、暂停、待收等含义不能仅依赖颜色。

## 本轮应用范围

商家登录与老板激活、全局导航和门店选择、实时连接状态、账号区、房态看板、快捷操作、技师卡片、收银金额区，以及各模块共用的表格、统计卡片、弹窗、按钮、输入框和空状态。平台登录、顾客入口与客户端版本窗口使用同一品牌。

首次访问默认舒适房态布局，仍可切换并保存紧凑布局。房态与技师区各自滚动，技师区仍可拖动或键盘调整；窄窗口的收银页保留完整操作并保证底部结账入口可见。

## 验证边界

视觉截图来自真实运行的界面；业务截图来自独立 `za_spa_saas_test` 中明确标记“验收”的商家。没有把这些账号或记录写入生产库。所有数值来自实际接口和测试业务记录。

检查宽度 1600、1050、375，包含手机登录、房态、开房弹窗和收银布局。完整业务回归与构建结果记录在 `STATUS.md`。本次视觉改版不等于全部原有业务功能已交付，不能把未完成模块当作可销售的正式版本。
