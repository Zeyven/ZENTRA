# 手动唤醒会员发券

旧版来源：ZuyuPOS-server/src/routes/leisure.js，POST /members/wake。
新入口：会员 → 智能分群 → 唤醒会员发券。

已实现：可设置券名、面值、门槛、有效期与未消费天数，向有效且从未消费或超过期限未消费的会员发放本店现金券。相同门店、会员、券名已有未使用有效券时跳过。单次超过 1000 人拒绝整批，提示使用营销自动化。操作有审计与实时通知；不发送短信。

SaaS 规则：单店会员限本店，通用会员在本商家共享，消费活跃度依据本商家各门店的已结账记录。冻结会员不参加。有效期限定 1–365 天，不沿用旧版无限期默认值。老板或具有优惠权限的店长可操作，支持会话不可操作。

验证：后端并发不同请求键、同键重试、同卡号跨商家和独立门店隔离、通用会员跨店发券；浏览器真实发券后丢响应、连续点击、表单锁定、原键核对。仅隔离测试环境，不代表生产上线或外部渠道联调完成。

本轮同时验证充值响应丢失后的本机持久恢复及网关 502 后原请求重试，见 member-assets.spec.ts 的三个充值恢复用例。
