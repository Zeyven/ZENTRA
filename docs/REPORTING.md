# 报表与提成口径

所有营业日按 Asia/Shanghai 的 00:00（含）至次日 00:00（不含）计算。查询强制当前商家及获授权门店；多条 SQL 使用同一数据库快照。

- 营业净额：当天实际结账折前额减优惠，加上当天发生的相反方向冲销；跨日开房按实际结账日入账。结账笔数与冲销笔数分列。
- 支付汇总：按付款和冲回发生日期显示原收、退回和净收款。充值、手牌押金、预约订金单独统计，不算项目销售。预约订金转消费应结合订金对账查看。
- 客流：按开房日期统计未取消订单组数，不能将订单数称为人数。
- 项目销量、优惠分配和参考利润：结账时写入不可更改的快照，反结账逐项反向写入。优惠按整数分最大余数法分配。成本为结账时商品成本、服务耗材配方成本和固定项目提成的参考值，不是实际已结工资或财务净利润。
- 技师业绩：已落钟、未赠送、未退单、订单未取消的服务；包含未结账服务。钟数按服务数量，加钟提成单独分项。未锁月工资使用当时规则计算。
- 工资锁定：保存人员信息、业绩、底薪、阶梯、复合规则、逐项计算与总额；锁定后工资报表读取快照。支持重复提交和空月份锁定。当前没有锁定后薪资调整流程，不能在界面承诺已提供该流程。
- 连锁会员：共享模式显示本商家会员；充值、消费及本金/赠金/次数分配仅统计所选门店发生流水。余额与权益是当前商家通用余额。
