- 官网技术咨询电话：400-8787-680。本轮未联系厂商或提交表单。

结论：公开检索暂未获得可实现的通信协议、SDK、报文示例或第三方接入授权说明。不能推断协议一定不存在，也不能宣称设备仅支持思软系统。设备操作系统、网络地址和产品功能说明不能代替通信协议。

## 需要确认

1. 门店实际设备完整型号、硬件版本、固件版本及当前连接拓扑；不能仅凭“康康驾到”确认型号。
2. 是否支持第三方管理系统，是否能通过官方设置修改服务端地址，是否需要中间网关或授权。
3. SDK 或协议版本、传输方式、连接发起方、默认端口、认证机制、设备身份与房间绑定方法。
4. 注册、心跳、呼叫、上下钟、加钟、刷卡、状态同步的请求与回执示例，以及错误码、重试和去重要求。
5. 测试设备、测试授权和可撤回原系统的配置步骤。

可转给厂商的咨询文字：

“我们有思软康康驾到配套房间点钟王，希望接入自有门店管理系统。请确认该型号和固件是否支持第三方接入，能否提供 SDK 或通信协议、鉴权方式、报文示例、设备与房间绑定及测试授权；是否需要专用网关或修改服务器地址。我们需要验证呼叫、点钟、上下钟和刷卡事件，请明确各项支持范围。”
