# ZA Thera 澜序实体店点钟王和刷牌器连接教程

适用对象：门店老板、店长和技术人员。

这份教程用于到店采集设备信息、完成网络和电脑连接，并做好系统接入前的验收记录。这里的“点钟王”指房间内的触控面板，用于顾客点钟、呼叫服务或提交房间操作；“刷牌器”指读取手牌、腕带或房卡的设备。

## 先确认系统边界

2026-09-09 更新：源码已增加点钟王 room_panel 接入准备配置（V1.0.2 已发布），仅登记本店设备名称、型号和预期连接方式；没有硬件通信能力。刷牌器有 wristband_reader 配置接口，仅保存名称、型号和连接方式；没有实际读卡驱动，测试接口固定返回 DEVICE_NOT_CONNECTED。当前这两类设备都不能按本教程直接完成澜序硬件联动。本文件仅供现场设备信息采集，不能作为已接通的安装验收教程。

## 到店前准备

准备以下物品：

- 点钟王触控面板、电源适配器、网线或无线网络资料。
- 刷牌器、电源线、USB 或串口线，必要时准备网线。
- Windows 10/11 电脑、设备厂商驱动和说明书。
- 一个测试房间、一个测试手牌或腕带、一个测试会员和一笔可撤销的测试订单。

拍下每台设备的铭牌，记录品牌、完整型号、序列号、接口类型和设备 IP。不要拍摄或提交支付密钥、管理员密码和真实会员资产。

## 连接点钟王触控面板

1. 在路由器或交换机上为点钟王预留网络端口。优先使用网线；如果必须使用无线网络，确认门店网络覆盖房间且不会在营业时切换网络。
2. 给点钟王接通电源，进入设备网络设置，记录设备 IP、网关、DNS 和端口。建议在路由器中为设备做 DHCP 地址保留，避免 IP 变化。
3. 在同一局域网的收银电脑上确认可以看到该设备。记录点钟王的通信协议、端口、厂商后台地址和心跳方式；这些信息需要交给技术人员做适配。
4. 本次新增“门店设置 → 设备接口 → 房间触控面板（点钟王）”准备入口已随 V1.0.2 发布，可保存本店名称、型号和预期连接方式；具体房间、网络地址和厂商资料仍需记录在外部设备清单中，待协议适配后联调。
5. 在正式接入前，用厂商自带的测试页面验证触控、网络心跳和设备重启后的自动上线。不要用真实顾客点击产生经营数据。

## 连接刷牌器

1. 确认刷牌器的接口是 USB、串口还是网络，并记录 USB 设备名称、COM 端口或 IP 与端口。
2. 安装厂商官方驱动。打开 Windows 设备管理器，确认没有黄色感叹号；串口设备要记录 COM 编号，网络设备要确认与收银电脑处于同一网段。
3. 刷牌器配置接口目前只接受名称、型号和连接方式，不能保存 IP、端口或 COM 参数。请把这些连接参数另行记录，配置保存也不表示可以读取实体卡片。
4. 点击设备测试。未完成协议适配时，系统会返回“DEVICE_NOT_CONNECTED”或未接入提示，这是当前产品边界，不代表设备一定损坏。
5. 完成官方协议适配后，再使用测试手牌验证读取卡号、绑定房间、读取会员、消费扣款和撤销。没有适配完成前，不要把卡号手工填入订单来冒充刷牌成功。

## 现场验收记录

| 项目 | 记录内容 |
|---|---|
| 门店 | 商家、门店、房间、操作人员、日期 |
| 点钟王 | 品牌、型号、序列号、IP、端口、网络方式、厂商协议 |
| 刷牌器 | 品牌、型号、USB/COM/IP 参数、驱动版本 |
| 系统 | 客户端版本、设备管理保存结果、测试返回内容 |
| 网络 | 收银电脑 IP、设备 IP、是否同一局域网、是否固定地址 |
| 现场结果 | 触控测试、心跳测试、刷牌读取测试、异常提示 |

## 常见问题

- 点钟王能开机但系统没有设备：检查是否同一局域网、IP 是否变化、端口是否被防火墙拦截，并记录厂商协议；不要直接修改系统数据库。
- 刷牌器在厂商工具中可读、澜序中不可读：通常是协议或驱动尚未适配。保留设备型号、驱动版本和测试日志，提交技术适配。
- 设备测试失败后仍然产生订单或扣款：立即停止测试，记录订单号和时间，不要重复刷牌或重复点击结账。
- 断网后设备恢复：确认点钟王不会重复提交点钟请求，刷牌器不会重复扣款；正式接入必须通过请求编号和服务端回执确认。

## 正式营业前检查

- 点钟王每个房间都能稳定上线，重启后地址不变。
- 刷牌器能读取测试手牌，并能正确返回设备编号和卡号。
- 测试点钟、绑定、结账和撤销各执行一次，数据库只产生一条对应记录。
- 设备断开时系统给出明确失败反馈，不显示虚假的成功状态。
- 技术人员保存设备清单、网络参数和测试日志；密码、支付密钥和真实会员数据不写入教程或截图。

请把完成后的设备清单、每台设备的品牌型号、接口参数和测试结果发给技术人员，再安排协议适配和正式联调。
