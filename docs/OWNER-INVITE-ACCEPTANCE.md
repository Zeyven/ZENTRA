# 老板邀请生命周期

平台可查看邀请状态、补发及撤销。所有查询仅返回状态与有效期，不返回历史令牌或哈希。补发生成新令牌并立即替换旧哈希；撤销使有效期立即失效。老板激活和补发/撤销锁定同一邀请行，避免并发创建多个老板。已使用的邀请不能补发或撤销，不修改已存在老板账号。

操作记录在平台审计中，不写入邀请秘密。补发链接只在本次响应中展示；丢失时再次补发会使此前链接失效。停用商家不能补发，恢复后可重试。平台页面具有独立老板邀请管理弹窗。

后端 2/2 通过，包含补发旧链接拒绝、撤销拒绝、激活后不能替换、激活与补发并发及商家凭证不能访问平台邀请。页面类型检查和浏览器补发/撤销通过。浏览器验收发现使用本机时间判断撤销状态会错误显示等待激活，现改为服务端返回状态；将浏览器时间固定到 2025 年仍能正确显示撤销并拒绝旧链接。
