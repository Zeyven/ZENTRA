# 1.0.0-rc.5 房态与员工个人权限（2026-09-08）

房态采用空闲绿、使用中蓝、待打扫黄、已预约紫、维修红，卡片背景、边框和统计图例统一，保留文字状态。

员工创建后直接进入门店授权。每店独立选择角色、功能模块和敏感操作；新授权默认不勾选，可明确采用该门店角色权限，再逐项调整。同角色员工彼此独立。门店角色禁用项仍是权限上限，老板管理能力不能授予员工。未授权门店不能访问；停用门店可维护授权但员工不能营业。

数据库 026 在 staff_store_grants 新增 pages/actions 数组，受原有商家 RLS 和复合外键保护。null 保留原角色策略，显式空数组不给予权限。老客户端省略个人权限字段时保留已有个人限制，不会静默恢复角色默认权限。现有账号不批量重置。

API 鉴权和 /permissions/self 使用相同的有效权限。权限变更发布实时通知，下一个请求重新校验；实时订阅和事件过滤执行个人模块权限。跨店调拨、原店充值冲销和已发领券凭据继续检查对应员工的个人授权，不能绕过。
