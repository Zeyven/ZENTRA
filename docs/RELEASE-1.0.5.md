# V1.0.5 店长门店设置权限

追加收银日常操作修复：服务端 page-access 对 session-items 路由缺失映射，导致加钟、落钟、派换技师等项目操作在非老板账号下全部被 MODULE_FORBIDDEN 拒绝。补齐至 board/orders 页面授权，保留角色、门店、商家和敏感操作授权校验；不开放钟房任意金额审批等其他权限。

收银真实浏览器补测通过：仅 board 页面授权的收银加钟 30 分钟成功；落钟原因可填写；明确授权后的赠单和退单成功且各提交一次；查询服务时长从 60 增至 90。未授权时的赠单、退款、改价及其他门店操作均返回 403。店长设置浏览器测试再次通过。

根因：共享 defaultPages.manager 显式排除 settings，导致角色上限和员工勾选项都不包含门店设置；POST /settings 同时只允许老板。

修复：店长角色默认包含 settings，允许老板按门店给员工勾选该模块；设置读取和保存均允许获授权店长。账号权限入口只向老板显示，服务端老板专属授权接口保持原有约束。已有明确的员工页面白名单及门店角色禁用项继续生效，不批量覆盖老板的权限设置。

验证：typecheck/build 通过；staff-permissions 和 page-permissions 共 6 项真实数据库测试通过，涵盖默认店长、显式授权、撤销授权、未授权门店、跨商家、禁止自改角色权限；manager-settings 和 staff-permissions 两项浏览器测试通过，实际登录、打开设置、保存、刷新、查询持久化结果及账号权限入口不可见。

本轮不迁移数据库、不修改生产员工权限记录、不操作经营资金。旧客户端需要升级到 V1.0.5，网页刷新后使用新模块上限。原先单独配置白名单的账号须由老板勾选“门店设置”；不能把更新代码视为绕过已有明确禁用。
