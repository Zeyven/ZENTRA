# ZA Thera｜澜序 1.0.13

2026-09-15，发布 API、Web 与 Windows 客户端 1.0.13。

- 桌面端与命令行点钟王网关统一读取本机已存在的原厂授权/菜单缓存；只在澜序网关授权、门店业态、设备编号、绑定和本机缓存均完整时提供受限的`SystemDeviceLogin`测试响应。
- 网关不调用厂商服务、不输出原厂授权信息；报钟、加钟、下钟及钟房播报继续明确拒绝，直到实机协议与回执完成验证。
- `HeadBeat`只接受现场观察到的 JSON 字符串形状；异常心跳断开连接，不能维持授权设备套接字。
- 修正`ReportClock`的现场嵌套请求结构记录；虚拟点钟王不再展示预置“使用中”房态或模拟订单，避免造成实机已接通的错觉。

验证：硬件网关相关测试 24/24 通过；全项目 TypeScript 类型检查、服务端构建、Web 构建通过。Windows 包 `ZA-Thera-1.0.13-Windows-x64.exe` 为 112,976,233 字节，SHA-256：`4845da607d9b11c50d980fe69cde8a8f75d1a06b014cd300288b52546ba62997`；打包核验 31 个受检文件通过。

本版没有数据库迁移。真实面板、钟房机顶盒和播报器仍未实机验收；未将合成 TCP 测试表述为真实厂商兼容。
