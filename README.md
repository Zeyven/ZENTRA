## 关于我

我不只关注代码如何实现，也关注一个产品为什么存在、解决什么问题，以及它最终能否真正运行在用户的业务中。

我主要工作在这些交叉领域：

| Product | Design | Engineering |
| --- | --- | --- |
| 产品定义与业务建模 | 信息架构与交互体验 | Web 应用与 API |
| 范围、优先级与交付路径 | 响应式体验与设计系统 | 数据库与数据流 |
| AI 场景与工作流设计 | 可访问性与操作效率 | 架构、部署与持续迭代 |

> **Software should make complexity disappear.**  
> 好的软件不是增加更多功能，而是让复杂的事情变得清晰。

## 能力

- **Product** — 从真实问题出发，明确产品边界、用户角色与业务规则
- **UX / UI** — 让信息有秩序，让关键操作变得自然
- **Full Stack** — 连接界面、服务与数据，让产品完整运行
- **AI Engineering** — 把模型能力放进具体场景，构建可用的工作流
- **Architecture** — 为模块、权限、数据和服务建立清晰边界
- **Delivery** — 覆盖验证、部署、监控、回滚与持续维护
