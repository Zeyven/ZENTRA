# ZENTRA Attribution

This document explains the ZENTRA attribution notice distributed with this
repository.

## Required attribution

The standard attribution text is:

```text
Powered by ZENTRA
```

For Chinese interfaces, the following form may be used:

```text
基于 ZENTRA
```

The attribution is a licensor notice included with the software.

Under Elastic License 2.0, licensing, copyright, and other notices of the
licensor in the software may not be altered, removed, or obscured.

## User interfaces

If the original ZENTRA software displays the attribution in its user interface,
redistributed or modified versions must keep that attribution reasonably
visible.

Acceptable placements include, for example:

- application footer
- About page
- Settings / About section
- login or splash screen
- other comparable, user-visible locations

The attribution may be restyled or repositioned to fit a modified interface,
provided that it remains readable and reasonably visible.

The following are not acceptable:

- removing the attribution
- hiding it behind a feature flag solely to suppress attribution
- making it effectively unreadable
- replacing ZENTRA with another name in a way that removes the original
  attribution
- presenting the notice in a misleading way that implies endorsement or
  ownership by another party

## Non-UI distributions

For command-line, server, library, or other non-graphical distributions, retain:

- LICENSE
- NOTICE
- this attribution document
- applicable copyright and licensing notices already included with the software
